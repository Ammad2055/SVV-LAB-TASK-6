| Constraint ID | Formal Constraint | Violation State | Explanation & Detection Method |
|---|---|---|---|
| C01 | train_approaching → warning_lights_on | train_approaching = true, warning_lights_on = false | A train enters the approach zone but the warning lights remain off, leaving road users unaware of the hazard. Detection: compare the train approach sensor output with the warning-light output and flag any mismatch. |
| C02 | (train_detected ∧ ¬track_clear) → barrier_down | train_detected = true, ¬track_clear = true, barrier_down = false | A train is present in the detection zone while the barrier stays raised, exposing vehicles to collision risk. Detection: evaluate the barrier actuator state when train_detected is true and the crossing is occupied. |
| C03 | barrier_down → road_signal_stop | barrier_down = true, road_signal_stop = false | The barrier lowers but the road signal still allows traffic, causing motorists to drive into a blocked crossing. Detection: verify the signal control logic against the barrier state. |
| C04 | (¬train_approaching ∧ track_clear) → (¬barrier_down ∧ road_signal_go) | ¬train_approaching = true, track_clear = true, ¬barrier_down = false or road_signal_go = false | The crossing remains closed even though the route is clear, causing unnecessary delay and possible queue formation. Detection: check whether the crossing is in a normal state but still blocking traffic. |
| C05 | sensor_failure → (degraded_mode ∧ maintenance_alert) | sensor_failure = true, degraded_mode = false, maintenance_alert = false | A track sensor fails silently without triggering degraded mode or a maintenance alert, leaving operators unaware of the fault. Detection: monitor sensor health and confirm mode transitions and operator alerts. |
| C06 | barrier_failure → (alarm_raised ∧ safe_stop_state) | barrier_failure = true, alarm_raised = false, safe_stop_state = false | The barrier mechanism jams in mid-operation and the system does not raise an alarm or force a safe stop. Detection: inspect actuator feedback, alarm triggers, and safe-state logic during barrier movement fault events. |
| C07 | communication_loss → (safe_stop_state ∧ maintenance_alert) | communication_loss = true, safe_stop_state = false, maintenance_alert = false | Control and field equipment lose communication, but the crossing continues normal operation without entering safe-stop or alerting maintenance. Detection: monitor heartbeat status and confirm fallback logic when the controller loses network connectivity. |
| C08 | emergency_mode → (warning_lights_on ∧ barrier_down ∧ ¬road_signal_go) | emergency_mode = true, warning_lights_on = false or barrier_down = false or ¬road_signal_go = false | Emergency response is active but crossing protection is not enforced, creating unsafe conditions for emergency and road traffic. Detection: validate emergency override logic against warning, barrier, and signal outputs. |
